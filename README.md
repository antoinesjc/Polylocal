# Polylocal

Code for [polylocal.eu](https://www.polylocal.eu).

| Folder | What it is |
| --- | --- |
| [`widgets/`](widgets/) | Bilingual (English and Traditional Chinese) widgets to embed in the Odoo site: the full homepage and the interactive corridor map |

Every widget switches language automatically with the site, so one embed serves both the English and the 繁體中文 pages.
